# Arena (west room, side-scroll) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 240 × 50 room west of the lobby. One photo is its back wall. Walking in through its door tilts the view from top-down to a side view with gravity, jumping and glowing platforms. Other real visitors run and jump there too.

**Architecture:**
- **Pure core:** `src/arena.js` parses the hand-drawn level (`src/arena.txt`) and holds the platform physics, the side-view camera and the photo crop. All of it is unit-tested in node.
- **Layout:** `src/layout.js` places the room, its corridor, its sign and one *backdrop* frame (the photo, covering the whole interior). It returns `map.arena`.
- **World:** `src/world.js` gains a `mode` (`'top'` | `'side'`). In side mode it hands the player to `arena.js`. Crossing the door sets `world.want`; `src/main.js` plays the tilt and then calls `enterSide` or `exitSide`. A teleport switches mode at once.
- **Drawing:**
  - `light.js` builds a second lighting for the side view (ambient 0.75, glowing platforms, no lantern).
  - Both renderers draw the backdrop and the platforms only in side mode.

**Tech Stack:** vanilla JS (ES modules), Vite 5 (`?raw` import for the level file), `node --test`, puppeteer e2e, `sharp` (already a devDependency) for one screenshot check.

**Spec:** `docs/specs/2026-10-13-arena-design.md`

## Global Constraints

- Config: `export const ARENA = { enabled: true, photo: 'img-4927' };` in `src/config.js`. `enabled: false` removes the arena, its corridor and its sign entirely.
- Room: `id: 'arena'`, `name: 'Arena'`. The interior is **240 × 50** cells, with walls around it. The door is on the east wall, in the bottom 3 interior rows, lined up with the 3 middle rows of a 5-row corridor. The corridor is **10** cells long (the darkroom corridor's length). The sign `← ARENA` is inside the lobby by the door.
- Level file `src/arena.txt`: **50 lines × 240 characters**. Space = air, `═` = platform (one-way), `▓` = solid. At runtime, any other character is air. The bottom 3 rows of the 4 columns next to the door must be air.
- Physics:
  - run 30, sprint 45 cells/s;
  - take-off 40 rows/s, gravity 133 rows/s², which is a jump of about 6 rows and about 0.6 s in the air;
  - releasing jump while rising halves the upward speed;
  - max fall 60 rows/s; air control 60%;
  - coyote time 0.1 s; jump buffer 0.1 s; drop-through 0.25 s;
  - box 0.6 wide × 1 row tall; sub-steps of under 0.4 cell;
  - you land on `═` only while falling, and only from above.
- Camera: horizontal lead in the running direction. With ≥ 52 rows in the view, the whole height is shown, centred. Otherwise the camera follows and keeps the floor in view near it. It is always clamped to the room.
- Transition: `perspective` + `rotateX` on `#stage`, 55°, 0.3 s out + 0.3 s in. Input is ignored during it. Reduce Motion = instant cut.
- Light: arena ambient **0.75** (neutral). Every `═`/`▓` cell has a warm-white core and a red-orange halo of radius ~3–4 cells. The lantern is off in the arena. Platform glyphs are bright warm white.
- Phones: `◀ ▶` bottom-left, `JUMP` bottom-right, `▼` above JUMP. Touch targets ≥ 56 px. They are shown only in the arena on touch screens. Portrait hint: `turn your phone sideways for the arena ↻`, which fades after 4 s or on a tap.
- In the arena: tap-to-walk is off. Follow is off, and it stops if either person enters. Fake visitors never enter. People inside are hidden from top-down views.
- The multiplayer protocol is unchanged. Hearts at the arena photo rise from the sender's `@`.
- Commits go to `main` locally. **Do not push** (the user batches pushes with the next release). Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **Window resized or phone rotated while in the arena:** the camera re-fits and re-clamps, and nothing outside the room shows. Pinned in Task 9 (resize e2e).
2. **Viewer opened on the arena photo, then →/← to another photo:** `standAt` teleports you out of the arena, so the mode must switch back to top-down at once, not leave you in side physics in a gallery room. Pinned in Task 4 (teleport sync unit test) and Task 9 (e2e).

```js
  // A standing spot reaches another if it is at most 5 rows up and within 12 columns (a jump is ~6 rows).
  const L = parseLevel(text);
  const at = (c, r) => (r < 0 ? AIR : L.cells[r * L.cols + c]);
  const surfaces = [{ row: L.rows, x0: 0, x1: L.cols - 1 }]; // the floor
  for (let r = 0; r < L.rows; r++) {
    let s = -1;
    for (let c = 0; c <= L.cols; c++) {
      const top = c < L.cols && at(c, r) !== AIR && at(c, r - 1) === AIR;
      if (top && s < 0) s = c;
      if (!top && s >= 0) { surfaces.push({ row: r, x0: s, x1: c - 1 }); s = -1; }
    }
  }
  const gap = (a, b) => Math.max(0, Math.max(a.x0, b.x0) - Math.min(a.x1, b.x1));
  const seen = new Set([0]), queue = [0];
  while (queue.length) {
    const i = queue.shift();
    surfaces.forEach((s, j) => {
      if (!seen.has(j) && surfaces[i].row - s.row <= 5 && gap(surfaces[i], s) <= 12) { seen.add(j); queue.push(j); }
    });

  const lost = surfaces.filter((_, j) => !seen.has(j)).map((s) => `row ${s.row} cols ${s.x0}-${s.x1}`);
  assert.deepEqual(lost, []);
});
```

```js
// The arena: a side-scrolling room. Pure: the level, platform physics, the side-view camera and the
// backdrop crop. world.js hands the player to stepBody while you're inside.

export const AIR = 0, PLATFORM = 1, SOLID = 2;
export const LEVEL_COLS = 240, LEVEL_ROWS = 50;

// src/arena.txt → one kind per interior cell, top row first. Anything unexpected is air, so a typo can't
// wall you in.
export function parseLevel(text, cols = LEVEL_COLS, rows = LEVEL_ROWS) {
  const cells = new Uint8Array(cols * rows);
  const lines = String(text).split('\n');
  for (let r = 0; r < rows; r++) {
    const chars = [...(lines[r] || '')];
    for (let c = 0; c < cols; c++) cells[r * cols + c] = chars[c] === '═' ? PLATFORM : chars[c] === '▓' ? SOLID : AIR;
  }
  return { cols, rows, cells };
}
```

```js
import { CELL_ASPECT } from './layout.js';

export const RUN = 30; // cells/s, the gallery's walking speed
export const SPRINT = 1.5;
export const JUMP_V = 40; // rows/s at take-off: with GRAVITY that is ~6 rows up, ~0.6 s in the air
export const GRAVITY = 133;
export const MAX_FALL = 60;
const ACCEL = 0.07; // seconds to reach about 63% of the target speed (as walking)
const AIR_CONTROL = 0.6;
const COYOTE = 0.1, BUFFER = 0.1, DROP = 0.25;
const HW = 0.3, HH = 0.5; // half width (cells), half height (rows)
const EPS = 1e-6;

export function newBody(x, y) {
  return { x, y, vx: 0, vy: 0, onGround: false, onPlatform: false, sinceGround: Infinity, sinceJump: Infinity, prevJump: false, cut: false, dropUntil: 0, t: 0 };
}

export function stepBody(b, dt, input, kindAt, { reducedMotion = false } = {}) {
  b.t += dt;
  const jump = !!input.jump;
  if (jump && !b.prevJump) b.sinceJump = 0; else b.sinceJump += dt;
  // Letting go while rising cuts the jump short.
  if (!jump && b.prevJump && b.vy < 0 && !b.cut) { b.vy *= 0.5; b.cut = true; }
  b.prevJump = jump;
  b.sinceGround = b.onGround ? 0 : b.sinceGround + dt;
  if (input.down && b.onGround && b.onPlatform) { b.dropUntil = b.t + DROP; b.onGround = false; }
  // A jump pressed a moment before landing, or a moment after running off a ledge, still counts.
  if (b.sinceJump <= BUFFER && b.sinceGround <= COYOTE) {
    b.vy = -JUMP_V;
    b.cut = false;
    if (!jump) { b.vy *= 0.5; b.cut = true; } // a buffered tap that was already let go: a short hop
    b.sinceJump = b.sinceGround = Infinity;
    b.onGround = false;
  }

  const target = (input.x || 0) * RUN * (input.run ? SPRINT : 1);
  const k = reducedMotion ? 1 : 1 - Math.exp((-dt * (b.onGround ? 1 : AIR_CONTROL)) / ACCEL);
  b.vx += (target - b.vx) * k;
  if (!target && Math.abs(b.vx) < 0.05) b.vx = 0;
  const vy0 = b.vy;
  b.vy = Math.min(MAX_FALL, b.vy + GRAVITY * dt);
  const mx = b.vx * dt, my = ((vy0 + b.vy) / 2) * dt; // exact for constant gravity

  const n = Math.max(1, Math.ceil(Math.max(Math.abs(mx), Math.abs(my)) / 0.4));
  const dropping = b.t < b.dropUntil;
  b.onGround = b.onPlatform = false;
  let hitY = false;
  for (let i = 0; i < n; i++) {
    moveX(b, mx / n, kindAt);
    if (!hitY) hitY = moveY(b, my / n, kindAt, dropping);
  }
}

function moveX(b, dx, kindAt) {
  if (!dx) return;
  const nx = b.x + dx;
  const col = dx > 0 ? Math.floor(nx + HW - EPS) : Math.floor(nx - HW);
  const r0 = Math.floor(b.y - HH + EPS), r1 = Math.floor(b.y + HH - EPS);
  for (let r = r0; r <= r1; r++) {
    if (kindAt(col, r) === SOLID) { b.x = dx > 0 ? col - HW : col + 1 + HW; b.vx = 0; return; }
  }
  b.x = nx;
}

// Returns true when the move was stopped (landed or bumped a ceiling).
function moveY(b, dy, kindAt, dropping) {
  if (!dy) return false;
  const ny = b.y + dy;
  const c0 = Math.floor(b.x - HW + EPS), c1 = Math.floor(b.x + HW - EPS);
  if (dy > 0) {
    const row = Math.floor(ny + HH - EPS);
    if (row > Math.floor(b.y + HH - EPS)) { // the feet cross into a new row: land on ▓ always, on ═ unless dropping
      let solid = false, platform = false;
      for (let c = c0; c <= c1; c++) { const k = kindAt(c, row); solid ||= k === SOLID; platform ||= k === PLATFORM; }
      if (solid || (platform && !dropping)) {
        b.y = row - HH; b.vy = 0; b.onGround = true; b.onPlatform = !solid;
        return true;
      }
    }
  } else {
    const row = Math.floor(ny - HH);
    if (row < Math.floor(b.y - HH)) {
      for (let c = c0; c <= c1; c++) {
        if (kindAt(c, row) === SOLID) { b.y = row + 1 + HH; b.vy = 0; return true; }
      }
    }
  }
  b.y = ny;
  return false;
}

// Where the side-view camera centres. a = the room with its walls, view = {cols, rows} on screen.
export function sideCamera(a, view, p, lead = 0) {
  const fit = (v, lo, hi) => (lo > hi ? (lo + hi) / 2 : Math.max(lo, Math.min(hi, v)));
  const x = fit(p.x + lead, a.x + view.cols / 2, a.x + a.w - view.cols / 2);
  if (view.rows >= a.h) return { x, y: a.y + a.h / 2 };
  // Near the floor, keep it on screen; higher up, keep you a little above the middle.
  const floorAtBottom = a.y + a.h - view.rows / 2;
  return { x, y: fit(Math.min(floorAtBottom, p.y + view.rows * 0.15), a.y + view.rows / 2, floorAtBottom) };
}

// The middle part of a w×h image with the shape of cols×rows cells.
export function coverCrop(w, h, cols, rows) {
  const want = cols / (rows * CELL_ASPECT);
  if (w / h > want) { const sw = h * want; return { sx: (w - sw) / 2, sy: 0, sw, sh: h }; }
  const sh = w / want;
  return { sx: 0, sy: (h - sh) / 2, sw: w, sh };
}
```

```js
// What fills a map cell in the side view: the level inside the arena, the building's walls outside it.
export function kindsFor(map) {
  const a = map.arena;
  return (cx, cy) => {
    const ix = cx - a.x - 1, iy = cy - a.y - 1;
    if (ix >= 0 && iy >= 0 && ix < a.cols && iy < a.rows) return a.level.cells[iy * a.cols + ix];
    return isWalkable(map, cx, cy) ? AIR : SOLID;
  };
```

```js
  for (let i = 0; i < map.W * map.H; i++) buf.set(ambient, i * 3);

  const halo = halos.length ? new Float32Array(map.W * map.H * 3) : null;
```

```js
// Keyboard and pointer input. Held keys become a movement vector; taps become commands. In the arena,
// W/↑/Space jump and S/↓ drop through platforms; the phone pad presses the same keys virtually.
const KEYS = {
  ArrowLeft: [-1, 0], KeyA: [-1, 0], ArrowRight: [1, 0], KeyD: [1, 0],
  ArrowUp: [0, -1], KeyW: [0, -1], ArrowDown: [0, 1], KeyS: [0, 1],
};
const JUMP = ['Space', 'KeyW', 'ArrowUp', 'Jump'];
const DROP = ['KeyS', 'ArrowDown', 'Drop'];

export function createInput(target, { onTap, onKey }) {
  const held = new Set();
  const pad = new Set(); // on-screen buttons held down
  let run = false; // Shift held: sprint instead of walking

  const editable = (e) => e.target.closest && e.target.closest('input, textarea, [contenteditable]');
  window.addEventListener('keydown', (e) => {
    if (editable(e) || e.metaKey || e.ctrlKey || e.altKey) return;
    run = e.shiftKey;
    if (KEYS[e.code]) { held.add(e.code); e.preventDefault(); return; }
    if (e.code === 'Space') held.add('Space'); // a jump in the arena; onKey decides what else it does
    if (onKey(e)) e.preventDefault();
  });
  window.addEventListener('keyup', (e) => { held.delete(e.code); run = e.shiftKey; });
  window.addEventListener('blur', () => { held.clear(); pad.clear(); });

  // Tap / click to walk (ignore drags)
  let down = null;
  target.addEventListener('pointerdown', (e) => { down = { x: e.clientX, y: e.clientY }; });
  target.addEventListener('pointerup', (e) => {
    if (!down) return;
    const moved = Math.hypot(e.clientX - down.x, e.clientY - down.y);
    down = null;
    if (moved < 10) onTap(e.clientX, e.clientY);
  });

  return {
    state() {
      let x = 0, y = 0;
      const all = new Set([...held, ...pad]);
      for (const code of all) { const k = KEYS[code]; if (k) { x += k[0]; y += k[1]; } }
      return { x: Math.sign(x), y: Math.sign(y), run, jump: JUMP.some((c) => all.has(c)), down: DROP.some((c) => all.has(c)) };
    },
    press(code, on) { if (on) pad.add(code); else pad.delete(code); },
    clear: () => { held.clear(); pad.clear(); },
  };
}
```

```js
function pixels(bitmap, w, h, crop = null) {
  const c = new OffscreenCanvas(w, h);

// cover: crop the middle of the image to the cells' shape instead of stretching it (the arena backdrop).
export function cellsFor(photo, cols, rows, mono, bitmap, cover = false) {
  const key = `${photo.id}:${cols}x${rows}:${mono ? 1 : 0}${cover ? ':cover' : ''}`;
```
